# Knowledge Base

Scope: this directory is the AI-managed knowledge base. Each subdirectory stores knowledge about a specific domain (e.g., `neovim/`).

## Rules

- When a question is asked about a domain that has a folder here, **search that folder's documents first** and base the answer on them.
- Relevant knowledge that is missing or hard to find elsewhere must be **stored in the corresponding domain folder**.

## Index

- `neovim/index.md` — Neovim knowledge base: how to use it and its documents.
- `opencode/index.md` — opencode knowledge base: data storage, session context usage, and how `session_context_usage` works.
