# Neovim Knowledge

Scope: this directory holds the AI-managed knowledge base about Neovim.

## How to Use This Knowledge

1. When the user asks a question about Neovim, **search the files in this folder first** and base the answer on what is found here.
2. If the subject is not covered here, **search the vanilla Neovim runtime docs** (the help `.txt` files under `/usr/share/nvim/runtime/doc/`) before answering, and base the answer on what is found there.
3. If there is relevant Neovim knowledge that is **not** present in these documents, or that is **hard to find** elsewhere, **store it in this folder** (a new `.md` file or a section in an existing one) so future answers can rely on it.

## Files

- `index.md` — this file: scope, usage rules, and index of documents in this directory.
